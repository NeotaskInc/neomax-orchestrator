# Project instructions

Keep project-specific architecture, repositories, safety constraints, deployment rules, and
working conventions in the project's own `CLAUDE.md` and `AGENTS.md`. Neomax discovers those
files from the directory where `neomax`, `cmax`, `cdxmax`, `ocmax`, `kmax`, or `gmax` starts.

An optional `docs/neomax-orchestrator/ORCHESTRATOR_OPENER.md` may add a short project-specific
orientation. Do not place credentials, personal home paths, or private customer data in the
neomax-orchestrator repository.
